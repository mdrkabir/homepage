01 / Selected research

Research Highlights

Selected work in LLM understanding, temporal modeling, interpretable reinforcement learning, and Bayesian inference.

2026LLM safetyPreprint

Different Paths to Harmful Compliance

Behavioral Side Effects and Mechanistic Divergence Across LLM Jailbreaks

This work compares harmful SFT, RLVR, and abliteration as three routes to unsafe model behavior. It evaluates both behavioral outcomes and internal representations, using CKA/RSA and refusal-repair probes to distinguish broad representational drift from targeted policy changes.

RLVRSFTAbliterationRepresentation analysis
Read paper ↗
2025Reinforcement learningAAAI

Deep Reinforcement Learning with Time-Scale Invariant Memory

This project develops a cognitively inspired memory architecture for temporal decision-making. The agent is designed to generalize across timing regimes instead of overfitting to the scale used during training.

Deep RLTemporal memoryCognitive AI
AAAI article ↗ Project ↗ Code ↗
2025Bayesian cognitionScience Advances

Path Integration Impairments Reveal Early Cognitive Changes

This work uses a hierarchical Bayesian model to separate path-integration errors into interpretable components and estimate group differences between participants with subjective cognitive decline and control participants.

NumPyroHierarchical BayesNavigation

Additional research

Earlier work in temporal modeling, cognitive reinforcement learning, and interpretable representations.

2026Computational Brain & Behavior

Time-Local Transformer

Integrated a log-compressed working-memory timeline into a Transformer, allowing it to learn long-range sequence dependencies without direct access to the full input history.

Transformers · Working memoryPaper ↗
2024CogSci

Evidence Accumulation in Deep RL

Embedded a cognitive model of sequential neural activity in deep RL agents trained on an evidence-accumulation task, producing task-related activity similar to neural sequences reported in the hippocampus.

Deep RL · Cognitive modelingPaper ↗
2023NeurReps

Geometry of Learned Knowledge

Used manifold learning to show that a deep RL agent's activity forms a low-dimensional space organized by task-relevant variables, providing an interpretable view of its decision process.

Manifold learning · InterpretabilityPaper ↗
2021Master's thesis

Humanlike Motion with Saltatory Rewards

Studied reward design and advantage estimation for physics-based character control by comparing modified PPO and A2C methods in a custom PyBullet humanoid environment.

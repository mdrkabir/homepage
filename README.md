# Md Rysul Kabir — Research Website

A self-contained static research portfolio inspired by Lambda's technical visual language.

## Open locally

Open `index.html` directly in a modern browser. No build process, package manager, or external JavaScript dependency is required.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive layout, visual system, and navigation animation
- `script.js` — navigation, Lambda-inspired label scrambling, active-section tracking, scroll progress, and reveal behavior
- `assets/rysul-portrait.jpg` — optimized portrait crop
- `assets/Md_Rysul_Kabir_CV.pdf` — current academic CV
- `assets/Md_Rysul_Kabir_resume.pdf` — current industry résumé
- `assets/favicon.svg` — site icon

## Included sections

Selected research, publications, experience, technical projects, education and presentations, academic service, awards, and contact.

## Document links

The résumé and academic CV are linked separately in the main navigation, hero,
and contact area. Both open their PDF in a new tab. Research remains the main
hero action, and the résumé is the highlighted document link in the header.

The bundled PDFs are unchanged from the supplied `new_webpage(4).zip`. To update
either document later, replace the corresponding file in `assets/` while keeping
its filename. No HTML edits are needed when the filenames remain unchanged.
